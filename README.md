# Evaluación Integrada de Física (50 Reactivos)

Este proyecto consiste en una plataforma de evaluación estandarizada orientada a la verificación de conocimientos y destrezas en Física General.

## 📁 Estructura del Proyecto

El repositorio está organizado según los siguientes archivos estáticos:

```text
├── index.html   # Estructura semántica, enlaces a CDNs (KaTeX, jsPDF, html2canvas) y contenedores modales.
├── index.css    # Estilos CSS3, variables globales, diseño responsivo y maquetación en grid/flexbox.
├── index.js     # Banco con los 50 reactivos, renderizado matemático, temporizador, persistencia en localStorage y controles anti-fraude.
└── README.md    # Documentación del proyecto.
